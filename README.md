# Malyala Mounika - Personal Developer Portfolio

A responsive, high-performance developer portfolio built with React 19 and Vite.

## 🚀 Live Demo & Deployment
- **Framework**: React + Vite
- **Styling**: Modern responsive dark UI with CSS variables and gradients
- **Icons**: Lucide React + custom SVG icons
- **Assets**: Verified resume bundled in `/public/resume.pdf`

## 🛠️ Project Structure
- `src/App.jsx`: Main single-page application with accessible navigation, hero section, about me, technical skills, featured projects, achievements, and direct contact options.
- `src/index.css`: Dark theme styling, glassmorphism cards, ambient light effects, responsive layouts, and typography.
- `public/resume.pdf`: Verified resume document for direct one-click download.
- `public/favicon.svg`: Custom developer logo badge favicon.

## 💻 Local Development
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run production build
npm run build

# Preview build locally
npm run preview
```

## 🌐 Deploy to Vercel
1. Run `vercel` in the project root, or
2. Import this repository on [vercel.com](https://vercel.com).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
